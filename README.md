# Network Provider Detector

This repository contains my Python project for detecting Nigerian network providers using phone number prefixes.

Contents:
- Python source code (`network_detector.py`)
- Screenshots showing output
- Project explanation and documentation

The program detects:
- MTN
- Airtel
- GLO
- 9mobile

It works by checking the first four digits of a phone number and matching them with known network prefixes.
